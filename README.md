## 四款 2697v2 的差别只在“线路 × 带宽”

硬件一模一样，2×E5 2697v2、256G DDR3、2TB SSD，四个 SKU 的变量只有两个：走 9929 还是 CN2 GIA，端口给 500Mbps 还是 1000Mbps。

9929 是中国联通的精品承载网，CN2 GIA 是中国电信那条高端线路。选哪个，看你的用户主要落在哪家运营商上。用户以联通、北方省份为主，9929 的表现就对得起钱；用户以电信为主，或者三网混杂、晚高峰不能掉链子，CN2 GIA 更稳。圣何塞的 CN2 GIA 到国内电信，第三方对 AkkoCloud VPS 线路的实测口径是 150–170ms，晚高峰的稳定性比普通直连线路好一截。独立服务器的实际路由未必和 VPS 完全一致，但方向可以参照。

带宽这一档更容易判断错。1000Mbps 适合持续有出流量压力的场景，比如视频分发、CDN 回源、大文件下载站。普通企业站、API 服务、跨境办公的 ERP，500Mbps 的端口根本跑不满，多花的钱买不到体验。反过来，如果你的业务是晚高峰集中爆发的下载型流量，500Mbps 会先卡在端口上，那时候线路再好也没用。

同配置下 GIA 的报价一般不会低于 9929，具体差额只能问，问的时候把两条线路的月付差价单独要一份，方便你算是否值得。

还有一件事页面上没写：这批机器有没有月流量上限，超了怎么算。独立服务器常见的是不限流量但限端口，也有给固定流量再降速的，必须在询价时确认清楚，否则 1000Mbps 跑满一个月可能出现意外账单。

## 256G 是 DDR3，这是最该想清楚的一处取舍

E5 2697v2 属于 Ivy Bridge-EP 世代，内存控制器只支持 DDR3；第五款的 E5 2650v4 是 Broadwell-EP，用的是 DDR4，容量却只有 128G。两边的优势不在同一个方向上。

跑数据库、缓存、虚拟化这类吃内存容量的活，256G DDR3 明显更实用。MySQL 的 buffer pool、Redis 的数据集、一台物理机上开十几台 KVM，瓶颈都是容量而不是内存带宽，128G 会先不够用。DDR3 的代价是内存带宽低、单核性能弱，后续想加内存条也不好找货。

单核性能敏感、内存带宽敏感、128G 够用的场景，比如编译、高并发短连接服务、单线程吃重的应用，v4 平台更合适。它的端口带宽也小得多，100M 国际 BGP、50M 9929、30M CN2 GIA 三选一，做小流量站点和 API 没问题，做大流量分发撑不住。

## 常见问题

**圣何塞机房回国延迟大概多少？**
第三方对 AkkoCloud 圣何塞 VPS 的实测口径是电信 CN2 GIA 150–170ms，联通和移动略高。独立服务器走的是同一机房的不同线路产品，实际路由要自己测。下单前用官网公开的 Looking Glass，或者直接向商家要测试 IP。

**9929 和 CN2 GIA 到底怎么挑？**
看用户主要用哪家宽带。联通用户多选 9929，电信用户多或者三网混杂选 CN2 GIA。两边都重要、预算够，就上 GIA 再配 1000Mbps。

**256G DDR3 会不会太老？**
老，但容量是实打实的。吃内存容量的业务它比 128G DDR4 好用，吃单核性能和内存带宽的业务反过来。先想清楚你的瓶颈在哪一边。

**能装 Windows 或者宝塔吗？**
官网分类页没有列操作系统选项，独立服务器一般可以自选系统，Windows 是否涉及授权费、能不能装面板，一并放进询价清单。

**需要备案吗？**
美国机房不涉及国内 ICP 备案，域名直接解析过去就能用。
